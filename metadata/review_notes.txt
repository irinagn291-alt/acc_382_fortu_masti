Fortu Masti runs on iPhone and iPad with iOS or iPadOS 17.0 or later. A fresh install opens on a playable Solo board at Juniper Pass with the tiger selected and the counter at 0 / 12. Tap B2 → C3 → B4 → A5 to reach “Tiger escaped” at 4 / 12. Open the atlas with the map button to verify the four-move record. In Solo, the device replies automatically. Before the match ends, Undo restores the position before the tiger move and the device reply. Once the result appears, moves and Undo are disabled.

To check shared play, select Juniper Pass and Two players in the atlas, then start the crossing. Move the tiger to B2. Select the warden at A4 and move it to B4. Control returns to the tiger, and Undo reverses the last individual move. The book button opens Field rules. Closing the atlas without starting a crossing preserves the current match. Confirm before replacing an unfinished match after its first tiger move.

The app saves the current crossing, undo history and best solo escape counts locally in a JSON file and restores the crossing on launch. Rules, opponent logic, artwork and translations are bundled. The app requests no runtime permissions and has no hardware-dependent workflows, network integrations, accounts, cloud sync, analytics, ads or purchases.
